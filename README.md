# VoiceTranslation

พากย์คลิปจาก **ซับไทย (.srt)** เป็น **เสียงภาษาอังกฤษ** สำหรับคลิป Facebook / YouTube / TikTok

- แปลด้วย **Claude** (Anthropic API) โดยรวมซับท่อนสั้น ๆ เป็นประโยคเต็ม แปลแบบภาษาพูดเป็นธรรมชาติ และคุมความยาวให้พูดทันเวลา
- สร้างเสียงด้วย **Kokoro-82M** ฟรี รันในเครื่อง ใช้เชิงพาณิชย์ได้ (Apache 2.0) มีเสียงอังกฤษให้เลือก 28 เสียง
- ได้ไฟล์ **.mp3** (เสียงพากย์), **.srt** (ซับอังกฤษที่ตรงกับเสียง) และ **.mp4** (ถ้าใส่คลิปต้นฉบับ)

ค่าใช้จ่ายมีแค่ค่าแปล ประมาณ $0.005 ต่อคลิป 1 นาที ส่วนอื่นฟรีทั้งหมด

## ติดตั้ง (Windows)

1. ดาวน์โหลดโปรเจกต์นี้: กดปุ่ม **Code → Download ZIP** บน GitHub แล้วแตกไฟล์ (หรือใช้ `git clone`)
2. ดับเบิลคลิก **`install.bat`**
   - ถ้ายังไม่มี Python สคริปต์จะติดตั้งให้ แล้วให้เปิด `install.bat` ใหม่อีกครั้ง
   - ถ้ามีการ์ดจอ NVIDIA จะติดตั้ง PyTorch รุ่นที่ใช้การ์ดจอให้อัตโนมัติ
   - ครั้งแรกจะดาวน์โหลดโมเดลเสียง Kokoro ประมาณ 330MB
   - ไม่ต้องติดตั้ง FFmpeg เอง เพราะโปรแกรมมีมาให้แล้ว
3. ขอ API Key ที่ [console.anthropic.com](https://console.anthropic.com) → **API Keys** แล้วเติมเครดิต ($5 ใช้ได้หลายร้อยคลิป)

## ติดตั้ง (Mac M1 / M2 / M3 / M4)

1. ดาวน์โหลดโปรเจกต์ (Code → Download ZIP) แล้วแตกไฟล์
2. ดับเบิลคลิก **`install.command`**
   - ครั้งแรก macOS อาจเตือนว่า "ไม่รู้จักผู้พัฒนา" ให้**คลิกขวา → Open → Open** (ทำครั้งเดียว)
   - ถ้าดับเบิลคลิกแล้วไม่ทำงาน ให้เปิด Terminal แล้วพิมพ์ `cd ` (เว้นวรรค) ลากโฟลเดอร์โปรเจกต์มาวาง กด Enter แล้วพิมพ์ `chmod +x *.command && ./install.command`
   - สคริปต์จะติดตั้ง Python ให้เองผ่าน `uv` ไม่ต้องลง Homebrew และดาวน์โหลดโมเดลเสียงประมาณ 330MB
3. ขอ API Key แบบเดียวกับ Windows
4. เปิดโปรแกรมด้วย **`start.command`**

บน Mac การสร้างเสียงจะใช้ CPU ซึ่งเร็วพอสำหรับโมเดลขนาดเล็กอย่าง Kokoro (ถ้าอยากลองใช้ GPU ของ Mac ให้ตั้งค่า `VOICETRANS_DEVICE=mps`)

## ใช้งานผ่านหน้าจอ

ดับเบิลคลิก **`start.bat`** (Windows) หรือ **`start.command`** (Mac) แล้วเบราว์เซอร์จะเปิดหน้าโปรแกรมขึ้นมา (ตัวโปรแกรมรันในเครื่องคุณ)

1. แท็บ **ตั้งค่า**: วาง API Key แล้วกดบันทึก ทำครั้งเดียว
2. แท็บ **1. แปล**: อัปโหลดไฟล์ `.srt` ภาษาไทย (และคลิปต้นฉบับ ถ้ามี) แล้วกด **แปล**
   - แก้คำแปลในช่อง English ได้ทุกบรรทัด
   - ใส่ "สไตล์การแปล" หรือ "คำเฉพาะ" (เช่น ชื่อช่อง ชื่อคน) ได้ในตัวเลือกการแปล
3. แท็บ **2. เสียงพากย์**: เลือกเสียง กด 🔊 ฟังตัวอย่าง แล้วกด **สร้างเสียงพากย์**
   - **ให้ Claude ย่อประโยคที่พูดไม่ทันเวลาอัตโนมัติ**: เปิดไว้จะดีที่สุด
   - **เก็บเสียงต้นฉบับไว้ข้างหลัง**: ตั้ง 0.1–0.2 ถ้าอยากให้ยังได้ยินเพลงพื้นหลังเบา ๆ (แต่จะได้ยินเสียงพูดภาษาไทยเบา ๆ ด้วย)
   - **ฝังซับอังกฤษลงในวิดีโอ**: เหมาะกับ TikTok / Reels

ไฟล์ผลลัพธ์อยู่ในโฟลเดอร์ `outputs\<ชื่อคลิป>_en\` และโหลดจากหน้าจอได้เลย ถ้าจะกลับมาแก้ทีหลัง ให้เปิดไฟล์ `.project.json` ในโฟลเดอร์นั้นจากแท็บแปล → "เปิดโปรเจกต์เดิม"

## ใช้งานแบบพิมพ์คำสั่ง

เปิด Command Prompt ในโฟลเดอร์โปรเจกต์ (บน Mac ใช้ Terminal แล้วพิมพ์ `source .venv/bin/activate` แทนบรรทัดแรก และใช้ `/` แทน `\` ใน path):

```bat
.venv\Scripts\activate
python dub.py voices                                        & rem ดูรายชื่อเสียง
python dub.py preview --voice bf_emma                       & rem ฟังตัวอย่างเสียง
python dub.py run clip.th.srt --video clip.mp4 --voice am_michael
python dub.py voice clip_en\clip.project.json --voice am_fenrir   & rem สร้างเสียงใหม่หลังแก้คำแปล
```

ตัวเลือกเพิ่มเติม: `--speed 1.1`, `--keep-original 0.15`, `--burn-subs`, `--no-fit`, `--model claude-opus-5-5`, `--style style.txt`, `--glossary glossary.txt`

## หลักการทำงาน

```
ซับไทย .srt ─► Claude รวมท่อนเป็นประโยค + แปล + คุมความยาว
            ─► Kokoro สร้างเสียงทีละประโยค (เร่งความเร็วได้ถึง 1.3 เท่าถ้ายาวเกิน)
            ─► ประโยคไหนยังยาวเกิน ให้ Claude ย่อแล้วสร้างใหม่ (สูงสุด 2 รอบ)
            ─► วางเสียงตามเวลาในซับ ─► .mp3 / .srt อังกฤษ / .mp4
```

| ไฟล์ | หน้าที่ |
|---|---|
| `app.py` | หน้าจอใช้งาน (Gradio) |
| `dub.py` | ใช้งานแบบพิมพ์คำสั่ง |
| `voicetrans/subtitles.py` | อ่าน/เขียน SRT |
| `voicetrans/translate.py` | แปลและย่อประโยคด้วย Claude |
| `voicetrans/tts.py` | สร้างเสียงด้วย Kokoro + รายชื่อเสียง |
| `voicetrans/timing.py` | จัดเวลาเสียงให้ตรงซับ + สร้างซับอังกฤษ |
| `voicetrans/media.py` | FFmpeg: ทำไฟล์ mp3 และรวมเข้าวิดีโอ |
| `voicetrans/project.py` | ไฟล์โปรเจกต์และขั้นตอนทั้งหมด |
